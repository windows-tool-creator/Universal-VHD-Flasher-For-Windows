# Universal-VHD-Flasher-For-Windows
A very cool tool that can be used to flash Windows and its server variants onto a virtual hard disk file (or .vhd and .vhdx)
How to use?
1. Double click the batch file
2. Choose what option your going to use
3. (For option 1) Input the drive letter of your attached vhd or vhdx
4. (For option 1) Input your location to the install.wim or esd
5. (For option 1) Select what index you want
6. Wait untill that finishes
7. (For option 1) If you want to slipstream drivers select Y
8. (if you select Y) Input the location to your driver folder
9. And your finished!
